# Üretim kategorileri uygulama görevi

- [x] Mevcut üretim, kayıt, ekonomi ve ekran yapısını incele.
- [x] Orman, Tarım, Hayvancılık, Maden ve ilgili sahaları tanımla.
- [x] Otomatik açılmayı kaldır; ücretli satın alma ve global iki kat fiyat kuralını uygula.
- [x] İşçi başına ekipman, aşınma, kırılma ve yükseltmeyi uygula.
- [x] Kategori müdürlerinin eksik ekipman taleplerini ekle.
- [x] Saha seviyeleri, işçi kapasitesi ve sınırlı rezervleri ekle.
- [x] Ahır ve ağılda tarif, bağımsız ürün ilerlemesi ve − / adet / + hedef kontrollerini ekle.
- [x] Kategori ve saha detay ekranlarını, depo grafiği ve yükseltmesini ekle.
- [x] Envanteri saatin yanına taşı.
- [x] Kayıt geçişi ve yeni sistem testlerini tamamla.
- [x] TypeScript kontrolü ve üretim derlemesini doğrula.
- [x] Hammaddesiz ürünleri sürekli üretime geçir; eksik hammaddeleri güncel stoktan hesapla.
- [x] Müdürleri isimli asistan bildirimlerine ve açılır pencerelere taşı.
- [x] Kategori kartlarına stok, çalışan saha, ekipman ve hammadde özetleri ekle.

Denge başlangıç değerleri: 250₺ sermaye, 100₺ ilk saha, 50₺ ilk saha yükseltmesi; saha alımları kategoriler arasında ortak fiyat dizisi kullanır. Ekipman yükseltmesi dayanıklılığı %100'e yeniler.

Görsel doğrulama sınırlaması: bağlı tarayıcı mevcut değildi. Arayüz etkileşimleri jsdom ortamında test edildi; gerçek tarayıcıda ekran görüntüsü kontrolü yapılamadı.
